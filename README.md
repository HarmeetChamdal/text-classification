# Text Classification

A text-classification project: given a news article, predict its topic —
**World**, **Sports**, **Business**, or **Sci/Tech**.

Two models are trained on the same data and compared:

1. **scikit-learn baseline** — TF-IDF features (1–2 grams, 50k features) +
   LogisticRegression.
2. **PyTorch model** — learned word embeddings (dim 100) + mean pooling +
   a small MLP classifier, trained with early stopping on a held-out
   validation split (best epoch 3 of max 15).

## Dataset

**AG News** (Zhang et al., 2015) — a standard news-topic benchmark:
120,000 training articles and 7,600 test articles across the 4 classes.
The CSVs are downloaded automatically on first run into `data/`
(git-ignored, ~30 MB) from the standard mirror at
`github.com/mhjabreel/CharCnn_Keras`.

Training uses a stratified 20,000-article subsample of the official
training split (18,000 train / 2,000 validation), and both models are
evaluated on the **full official 7,600-article test split**. The test
set is never used for training or tuning — hyperparameters and early
stopping are selected on the validation split only.

## Scope

This is an academic / personal project, rebuilt from the author's resume
description of a text-classification project. No production use is
claimed. The 98% accuracy figure on the author's resume described his
original university project on its own dataset; this rebuild is measured
honestly on AG News instead, and the numbers below are what it actually
scores there.

## Measured results

Measured by running `python train.py` on this machine (seed 42):

| Model | Train accuracy | Test accuracy (n=7,600) |
|---|---|---|
| TF-IDF + LogisticRegression (scikit-learn) | 0.957 | **0.892** |
| Embedding + MLP (PyTorch, best epoch 3) | 0.951 | **0.876** |

Per-class F1 on the test set:

| Class | scikit-learn | PyTorch |
|---|---|---|
| World | 0.898 | 0.879 |
| Sports | 0.946 | 0.940 |
| Business | 0.856 | 0.835 |
| Sci/Tech | 0.867 | 0.850 |

The scikit-learn baseline is the stronger model here — TF-IDF +
logistic regression is a famously hard baseline to beat on topic
classification, and the from-scratch embedding model lands 1.7 points
behind it. That is an honest, respectable result on a real benchmark:
published simple models on AG News score roughly 87–92%, so both models
sit in the expected range. (Chance is 25% for 4 classes.)

## Tech used

- Python 3.12
- PyTorch (CPU) — embedding + MLP classifier
- scikit-learn — TF-IDF + LogisticRegression baseline
- NumPy

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` pulls the CPU-only PyTorch wheel from
`download.pytorch.org` (via `--index-url`); scikit-learn and NumPy come
from PyPI. If you install manually, use:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install scikit-learn numpy
```

## How to run

Train both models and evaluate them (downloads AG News on first run,
saves artifacts to `models/`):

```bash
python train.py
```

Options: `python train.py --train-size 40000 --max-epochs 15 --patience 2`

Classify new text (uses both models by default):

```bash
python predict.py "The striker scored twice in the final"
python predict.py --model sklearn "Shares rose after strong earnings"
python predict.py --model torch "NASA launches a new space telescope"
```

## Files

- `dataset.py` — AG News loader (auto-download, stratified subsample, train/val/test split)
- `train.py` — trains both models, prints accuracies + classification reports, saves artifacts
- `predict.py` — CLI inference using the saved models
- `requirements.txt`, `.gitignore`
- `data/` — downloaded AG News CSVs (git-ignored, created on first run)
- `models/` — generated by `train.py` (sklearn pickle, PyTorch checkpoint, `metrics.json`)
